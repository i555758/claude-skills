# csb-05-html — Render HTML Report

HTML is generated by `data/generate_html.py` (Python 3). Run with auto-install prompt:

```bash
OUTPUT_DIR="C:/Users/${USERNAME}/OneDrive - SAP SE/Presentations/Customer-Project-Status-Board"
if python --version > /dev/null 2>&1; then
  python "$OUTPUT_DIR/data/generate_html.py"
else
  # Python not found — ask user if they want to install via winget (Windows 11+)
  echo ""
  echo "Python nao encontrado. Ele e necessario para gerar o relatorio mais rapidamente."
  echo "Deseja instalar Python agora? (requer internet, ~5MB, sem reinicializacao)"
  echo "[S] Instalar via winget   [N] Continuar sem Python (geracao mais lenta)"
  read -r REPLY
  if [[ "$REPLY" =~ ^[Ss]$ ]]; then
    echo "Instalando Python 3..."
    powershell.exe -Command "winget install --id Python.Python.3 --source winget --silent --accept-package-agreements --accept-source-agreements"
    # refresh PATH in current shell
    export PATH="$PATH:/c/Users/${USERNAME}/AppData/Local/Programs/Python/Python3*/:/c/Users/${USERNAME}/AppData/Local/Programs/Python/Python3*/Scripts/"
    if python --version > /dev/null 2>&1; then
      echo "Python instalado. Gerando relatorio..."
      python "$OUTPUT_DIR/data/generate_html.py"
    else
      echo "WARN: Instalacao concluida mas Python ainda nao esta no PATH desta sessao."
      echo "Feche e reabra o Claude Code, depois execute novamente."
      echo "Continuando com geracao inline por agora..."
      # fallback: generate HTML inline (see spec below)
    fi
  else
    echo "Continuando sem Python — geracao inline ativada."
    # fallback: generate HTML inline (see spec below)
  fi
fi
```

The script reads `portfolio.json`, `itsm.json`, `comms.json`, `crossref.json` from `data/`,
resolves the next sequence number, writes `CSB_{YYYYMMDD}_{NNN}.html` to `OUTPUT_DIR`,
and updates `progress.txt` to `STEP:5:7:HTML saved`.

Expected output: `Saved: …/CSB_{YYYYMMDD}_{NNN}.html  (NNkB)` — runs in under 5 seconds.

**Note:** Python is not guaranteed on colleague machines (this skill is distributed via the shared
CMP installer). Always check with `python --version` first and fall back to inline generation if
unavailable. The script itself requires no `pip install` — stdlib only.

## Panel spec (for fallback / reference)

- **Dashboard**: KPI strip (📁 projects · 🎫 cases · ⏱ weeks · 📧 unread · 📅 events) + project table (Project|Stage|Status|Partner|Wave|Phase|Planned Go-Live|Go-Live|Weeks Out|Alert) + Live collapsible
- **Next Actions**: `.card` elements from `crossref.nextActions[]`
- **Prioritized TODO**: `.todo-item.p1/p2/p3` from `crossref.todos[]`
- **Cases & WCR**: tables from `itsm.cases` / `itsm.wcr`
- **Partner Health**: table with Risk Signal (🔴🟡🟢⚫) computed from portfolio
- **Go-Live Timeline**: CSS timeline from portfolio + `crossref.goLiveChanges[]`
- **Meeting Prep**: subtabs Hoje/Amanhã + meeting cards (`.has-alert` if Red) + key email signals
- **Projetos**: `.proj-grid` of `.proj-card` per active project

## Security

Apply `esc()` to all scraped content before inserting into HTML:
```python
def esc(s):
    s = str(s) if s is not None else ''
    return (s.replace('&','&amp;').replace('<','&lt;')
             .replace('>','&gt;').replace('"','&quot;')
             .replace("'","&#39;"))
```
